# 任务系统扩展设计

## 一、设计目标

- 任务系统从「接→做→交」三明治升级为多阶段叙事
- 所有任务操作（接取/提交/领奖）统一走 NPC 交互，面板只做日志查阅
- NPC 与任务的交互通过对话菜单驱动
- 提供可视化任务树编辑器，让任务配置归并化、结构化

## 四、QuestManager 扩展

### 4.1 进度管理

```
接受任务 → 初始化第一阶段
阶段目标完成 → 推进到下一阶段
最终阶段完成 → 任务可提交
提交(对话中领奖) → 发放奖励 → 任务完成
```

### 4.2 核心方法

```csharp
public class QuestManager
{
    // 接取任务
    public bool AcceptQuest(string questId);

    // 获取当前阶段
    public QuestStage GetCurrentStage(string questId);

    // 获取当前阶段进度
    public int[] GetStageProgress(string questId);

    // 推进到下一阶段
    public bool AdvanceToNextStage(string questId);

    // 检查当前阶段是否完成
    public bool IsCurrentStageComplete(string questId);

    // 领取阶段奖励
    public bool ClaimStageReward(string questId);

    // 领取最终奖励→任务完成
    public bool ClaimFinalReward(string questId);

    // 放弃任务
    public bool AbandonQuest(string questId);
}
```

### 4.3 事件

```csharp
// 已有
OnQuestAccepted(string questId)
OnObjectiveUpdated(string questId, int objIndex, int current)
OnQuestFailed(string questId)

// 新增
OnQuestStageChanged(string questId, string stageId)
OnQuestReadyToClaim(string questId)
OnQuestClaimed(string questId)
```

### 4.4 新状态

```
未接取     → 在 GetAvailableQuests() 中
进行中     → 有 currentStageId，目标逐步完成
阶段可提交  → 当前阶段目标完成，待找 NPC 推进
可领奖     → 最终阶段完成，待找 NPC 领奖
已完成     → 最终奖励已领取
已失败     → 时间超限/条件失败
```

## 五、NPCQuestGiver 组件

挂在 NPC 上，和 `NPCBehaviour` 协作。

```csharp
public class NPCQuestGiver : MonoBehaviour
{
    [Header("NPC 标识")]
    public string npcId;                    // 与 NPCBehaviour 对应

    [Header("关联任务")]
    public List<QuestData> questsToGive;     // 所有绑定的任务

    [Header("问候对话")]
    [TextArea] public string[] greetingLines; // 无事时的闲聊

    // ─── 运行时查询 ───

    // 是否有可接取的任务
    public bool HasAvailableQuest()
    {
        foreach (var q in questsToGive)
            if (QuestManager.Instance.IsQuestAvailable(q.questId))
                return true;
        return false;
    }

    // 是否有可提交的阶段（当前阶段完成 but 不是最终阶段）
    public bool HasStageToSubmit()
    {
        foreach (var q in questsToGive)
        {
            if (!QuestManager.Instance.IsActive(q.questId)) continue;
            if (QuestManager.Instance.IsCurrentStageComplete(q.questId))
                return true;
        }
        return false;
    }

    // 是否待领最终奖励
    public bool HasFinalRewardToClaim()
    {
        foreach (var q in questsToGive)
            if (QuestManager.Instance.IsReadyToClaim(q.questId))
                return true;
        return false;
    }
}
```

### 对话菜单显示规则

```
菜单项     | 显示条件
──────────┼──────────────────────
📋 任务    | HasAvailableQuest || HasStageToSubmit || HasFinalRewardToClaim
🏪 商店    | NPCBehaviour.shopData != null
💬 对话    | 始终显示（greetingLines）
🚪 离开    | 始终显示
```

### NPCBehaviour 扩展

```csharp
// Update() 中按 F 的处理变为:
```

## 六、任务对话面板

### 6.1 面板参数

```csharp
public class UI_QuestDialogue : MonoBehaviour
{
    // 引用
    [SerializeField] private TextMeshProUGUI npcNameText;
    [SerializeField] private TextMeshProUGUI dialogueText;
    [SerializeField] private RectTransform questInfoRoot;  // 任务详情容器
    [SerializeField] private Button primaryButton;         // 主要操作
    [SerializeField] private Button secondaryButton;       // 次要操作

```

### 6.2 呈现模式

```
接取(任务预览 + 接受/拒绝)
  → primaryButton: [接受] → QuestManager.AcceptQuest() + 关面板
  → secondaryButton: [下次再说] → 关面板

进行中(对话 + 当前进度)
  → primaryButton: [继续] → 关面板
  → secondaryButton: 隐藏

阶段完成(阶段奖励 + 下一阶段预览)
  → primaryButton: [继续] → QuestManager.AdvanceToNextStage() + 刷新面板
  → secondaryButton: 隐藏

任务完成(最终奖励预览 + 领奖)
  → primaryButton: [领取奖励] → QuestManager.ClaimFinalReward() + 关面板
  → secondaryButton: [离开] → 关面板
```

### 6.3 输入阻塞

```
打开时 ModalStack.Push("quest_dialogue")
关闭时 ModalStack.Pop("quest_dialogue")
```

## 七、NPC 头顶标识

```csharp
public class QuestIndicator : MonoBehaviour
{
    [SerializeField] private GameObject exclamationMark;   // !
    [SerializeField] private GameObject questionMark;      // ?
    [SerializeField] private float floatHeight = 0.3f;
    [SerializeField] private float floatSpeed = 2f;

    private NPCQuestGiver giver;

    void Update()
    {
        if (giver.HasFinalRewardToClaim())
            questionMark.SetActive(true);     // 优先显示 ?
        else if (giver.HasStageToSubmit())
            questionMark.SetActive(true);     // 阶段可提交也显示 ?
        else if (giver.HasAvailableQuest())
            exclamationMark.SetActive(true);  // 有可接显示 !
        else
        {
            exclamationMark.SetActive(false);
            questionMark.SetActive(false);
        }
    }
}
```

## 十、可视化任务树编辑器（二期）

### 10.1 功能目标

- 在 Unity 编辑器窗口中以节点图形式创建/编辑任务
- 节点间的连线表示前置→后续关系
- 右侧属性面板直接编辑 `QuestData` 全部参数
- 一键导出为 QuestData ScriptableObject

### 10.2 技术栈

```
UnityEditor.Experimental.GraphView → 画板 + 节点 + 连线
UIToolkit → 属性面板 UI
ScriptableObject → 持久化存储
AssetDatabase → SO 创建/保存
```

### 10.3 编辑器布局

```
┌─────────────────────────────────────────────┐
│ 📋 任务树编辑器                               │
│                                              │
│  ┌────────────────────┐  ┌───────────────┐   │
│  │                     │  │  属性面板      │   │
│  │   画板(GraphView)    │  │               │   │
│  │                     │  │  questId:     │   │
│  │  [任务A]──▶[任务B]   │  │  questName:   │   │
│  │   │                 │  │  type: ○主线  │   │
│  │   ▼                 │  │       ○支线  │   │
│  │  [任务C]            │  │               │   │
│  │                     │  │  阶段列表:     │   │
│  │                     │  │  ┌─────────┐ │   │
│  │                     │  │  │ 阶段1   │ │   │
│  │                     │  │  │ 阶段2   │ │   │
│  │                     │  │  └─────────┘ │   │
│  └────────────────────┘  └───────────────┘   │
├──────────────────────────────────────────────┤
│ [保存]  [导出SO]  [从SO导入]  [+新任务]       │
└──────────────────────────────────────────────┘
```

### 10.4 节点设计

每个任务节点包含：

```
┌──────────────────────┐
│ 📦 铁匠的委托         │  ← 任务名
│ [主线]                │  ← 类型标签（彩色）
│ ──────────────────   │
│ 阶段1: 清理蝙蝠       │  ← 阶段列表（可展开收缩）
│ 阶段2: 击败蝙蝠王     │
│ ──────────────────   │
│ 前置 → 后续           │  ← 端口（连线用）
│ [输入]  [输出]         │
└──────────────────────┘
```
