# 存档系统设计方案

> 类银河恶魔城 Unity 2D 动作RPG  
> **版本**：v1.0  
> **日期**：2026-07-21  
> **基于**：项目 190 个脚本完整分析

---

## 一、设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 存档方式 | 检查点存档 | 场景中放置固定存档点，玩家走到旁边按交互键存档 |
| 文件格式 | JSON | 可读、好调试、易扩展 |
| 槽位数量 | 3 手动 + 1 自动 | 自动槽用于退出时自动存档 |
| 死亡复活 | 回到存档点 + 场景重置 | 保留玩家数据，场景怪物/宝箱/门重置 |
| 场景状态 | 不保存，读档全重置 | 简化实现，类银河城传统 |
| 物品 ID 体系 | 复用已有 `ItemDataSo.itemId` | CSV 导入已生成（100101=木剑等），无需改造 |

## 二、整体架构

```
SaveManager（单例，DontDestroyOnLoad）
  ├─ Save(slotIndex)    — 收集各系统数据 → 序列化 → 写文件
  ├─ Load(slotIndex)    — 读文件 → 反序列化 → 切换场景 → 恢复数据
  ├─ Delete(slotIndex)  — 删除存档
  ├─ ListProfiles()     — 获取所有槽位元数据（主菜单显示用）
  └─ QuickSave()        — 自动槽快速存档

各系统暴露 SaveState() / LoadState():
  Entity_Health         — currentHP
  Entity_Stats          — 21 个 Stat.baseValue
  PlayerLevelManager    — currentLevel, currentExp, skillPoints, attributePoints
  SkillPointManager     — totalSkillPoints, usedSkillPoints
  SkillDataManager      — GetAllSkillLevels() 返回 Dictionary<SkillUpgradeType, int>
  SkillSlotManager      — GetUpgradeTypeInSlot(0-4)
  Inventory_Player      — 所有物品（itemId + stackSize + rarity + slotIndex）
  EquipmentSystem       — 所有装备槽（itemId + itemType + slotIndex + rarity）
  QuestManager          — activeQuests + completedQuests + failedQuests + trackedQuestId

文件位置：Application.persistentDataPath/
  slot_0.json          手动槽 0
  slot_1.json          手动槽 1
  slot_2.json          手动槽 2
  slot_auto.json       自动存档
  profiles.json        元数据索引（场景名 + 等级 + 时间 + 截图名，主菜单快速展示）
```

## 三、存档数据结构

### SaveData（顶层）

```csharp
[Serializable]
public class SaveData
{
    public int version = 1;           // 存档格式版本（未来兼容）
    public string saveTime;           // DateTime.UtcNow.ToString("O")
    public float playTime;            // 游戏总时长（秒）
    public string sceneName;          // 玩家所在场景名
    public float posX, posY, posZ;    // 玩家位置
    public string lastCheckpointId;   // 最近存档点 ID
    
    public PlayerSaveData player;
    public List<StatSaveEntry> stats;
    public List<InventorySlotData> inventory;
    public List<EquipSlotData> equipment;
    public SkillSaveData skills;
    public QuestSaveData quests;
}
```

### PlayerSaveData — 角色核心数据

```csharp
[Serializable]
public class PlayerSaveData
{
    public float currentHP;
    public int currentLevel;
    public int currentExp;
    public int unspentSkillPoints;      // PlayerLevelManager.skillPoints
    public int unspentAttributePoints;   // PlayerLevelManager.attributePoints
    public int totalSkillPoints;         // SkillPointManager.totalSkillPoints
    public int usedSkillPoints;          // SkillPointManager.usedSkillPoints
}
```

### StatSaveEntry — 属性值

```csharp
[Serializable]
public class StatSaveEntry
{
    public int statType;       // (int)StatType（MaxHP=0, Strength=2, ..., LightningResistance=20）
    public float baseValue;    // Stat.baseValue（修饰符由装备/技能重新应用，不需要存）
}
```

**为什么用 int 而不是 string**：
- 枚举改名不影响 int 值，存档不损坏
- 编译期检查，不存在拼写错误
- `Entity_Stats.GetStatByType((StatType)entry.statType)` 直接还原

### InventorySlotData — 背包物品

```csharp
[Serializable]
public class InventorySlotData
{
    public string itemId;             // ItemDataSo.itemId（如 "100101"=木剑）
    public int stackSize;
    public int slotIndex;
    public int? rarity;               // LootRarity 枚举值（普通=0, 精良=1, 稀有=2, 史诗=3, 传说=4）
    public float rarityMultiplier;    // 稀有度属性倍率
}
```

rarity/rarityMultiplier 为 null/0 表示普通物品（非掉落生成）。掉落物品拾取后品质已确定，必须保存。

### EquipSlotData — 装备槽

```csharp
[Serializable]
public class EquipSlotData
{
    public string itemId;
    public int itemType;              // (int)ItemType（武器/头盔/盔甲/靴子/手套/饰品）
    public int slotIndex;
    public int? rarity;
    public float rarityMultiplier;
}
```

### SkillSaveData — 技能

```csharp
[Serializable]
public class SkillSaveData
{
    public List<SkillLevelEntry> learned;       // 所有已学习的技能及等级
    public int[] slotBindings;                   // 5 个槽位：每个存 (int)SkillUpgradeType
}

[Serializable]
public class SkillLevelEntry
{
    public int upgradeType;    // (int)SkillUpgradeType（如 Dash_Distance=1）
    public int level;          // 当前等级
}
```

被动技能由 `learned` 覆盖——被动技能等级 > 0 即已激活，不需要单独存储。

### QuestSaveData — 任务

```csharp
[Serializable]
public class QuestSaveData
{
    public List<QuestSaveEntry> active;          // 进行中
    public List<string> readyToClaim;            // 已完成条件、等待领取
    public List<string> completed;               // 已领取奖励
    public List<string> failed;                  // 已失败
    public string trackedQuestId;                // 当前追踪
}

[Serializable]
public class QuestSaveEntry
{
    public string questId;
    public List<QuestObjectiveData> objectives;
}

[Serializable]
public class QuestObjectiveData
{
    public int index;
    public int currentCount;
}
```

## 四、存档流程

### 存（Save）

```
触发：玩家在检查点按交互键 → 确认弹窗 → 选槽位 → 确认

SaveManager.Save(slotIndex):
  1. var data = new SaveData();
  2. data.sceneName = SceneManager.GetActiveScene().name;
  3. data.posX/Y/Z = player.transform.position;
  4. data.player = CollectPlayerData();
  5. data.stats = CollectStatData();          // 遍历 StatType 枚举 → GetStatByType → GetBaseValue
  6. data.inventory = CollectInventory();     // 遍历 Inventory_Player.itemDictionary
  7. data.equipment = CollectEquipment();     // 遍历 EquipmentSystem 装备字典
  8. data.skills = CollectSkillData();        // SkillDataManager.GetAllSkillLevels + SlotManager.GetUpgradeTypeInSlot
  9. data.quests = CollectQuestData();        // QuestManager 全部字典/HashSet
  10. data.saveTime = DateTime.UtcNow.ToString("O");
  11. File.WriteAllText(path, JsonUtility.ToJson(data, prettyPrint: true));
  12. UpdateProfiles();                       // 更新元数据索引
```

### 读（Load）

```
触发：主菜单点"继续游戏" / 死亡后回到检查点

SaveManager.Load(slotIndex):
  1. 读文件 → JsonUtility.FromJson<SaveData>()
  2. 如果 sceneName 和当前场景不同 → SceneManager.LoadScene(sceneName)
     等待场景加载完成
  3. player.SetPosition(posX, posY, posZ)
  4. Entity_Health.SetCurrentHP(data.player.currentHP)
  5. PlayerLevelManager.LoadFromSave(level, exp, skillPts, attrPts)
  6. SkillPointManager.LoadFromSave(totalSkillPts, usedSkillPts)
  7. RestoreStats(data.stats)                // 逐个 SetBaseValue
  8. RestoreInventory(data.inventory)        // ItemDataSo.itemId → Resources.Load → new Inventory_Item
  9. RestoreEquipment(data.equipment)        // 从背包找到物品 → 装备到槽位
  10. RestoreSkills(data.skills)             // SkillDataManager.UpdateSkillData + SkillSlotManager.BindSkillToSlot
  11. RestoreQuests(data.quests)             // 重建 QuestManager 内部状态
  12. 场景自动重置（所有敌人复活、宝箱恢复）— 不需要手动操作，读档=场景重新加载
```

### 物品重建

```
RestoreInventory(slotData):
  foreach (var entry in data.inventory):
    ItemDataSo itemData = ItemLookup.Find(entry.itemId);
    // ItemLookup: Dictionary<string, ItemDataSo>，在 Awake 时从 Resources 扫描构建
    Inventory_Item item;
    if (entry.rarity.HasValue && entry.rarityMultiplier > 0):
      // 有品质信息的物品（原为掉落物）
      var looted = new LootedItem { baseItemData = itemData, actualRarity = (LootRarity)entry.rarity, statMultiplier = entry.rarityMultiplier };
      item = new Inventory_Item(looted);
    else:
      item = new Inventory_Item(itemData);
    item.currentStackSize = entry.stackSize;
    inventory.AddItem(item, entry.slotIndex);
```

## 五、物品查找（ItemLookup）

建立 `itemId → ItemDataSo` 运行时映射，用于读档时重建物品。

```csharp
public static class ItemLookup
{
    private static Dictionary<string, ItemDataSo> _cache;

    public static void Initialize()
    {
        _cache = new Dictionary<string, ItemDataSo>();
        var allItems = Resources.LoadAll<ItemDataSo>("Items");
        foreach (var item in allItems)
        {
            if (!string.IsNullOrEmpty(item.itemId))
                _cache[item.itemId] = item;
        }
    }

    public static ItemDataSo Find(string itemId)
    {
        _cache.TryGetValue(itemId, out var result);
        return result;
    }
}
```

**前提**：所有 `ItemDataSo` 的 ScriptableObject 放在 `Assets/Resources/Items/` 下。CSV 导入工具生成的 SO 文件需要确保输出路径在 Resources 中。

## 六、检查点系统

### 交互设计
- **触发**：走进检查点范围 → 提示 UI "按 F 存档" → 按 F → 直接存档
- **冷却**：存档后 2 秒 CD，防止反复触发
- **按键**：`GameInput.Action.Interact`，默认 `KeyCode.F`
- **特效**：存档成功后短暂光效 + 音效（DOTween）

```csharp
public class Checkpoint : MonoBehaviour
{
    public string checkpointId;
    public Transform respawnPoint;
    private bool playerInRange;
    private float lastSaveTime;

    void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Player")) { playerInRange = true; ShowPrompt(true); }
    }
    void OnTriggerExit2D(Collider2D other)
    {
        if (other.CompareTag("Player")) { playerInRange = false; ShowPrompt(false); }
    }
    void Update()
    {
        if (playerInRange && GameInput.GetKeyDown(GameInput.Action.Interact) && Time.time - lastSaveTime > 2f)
        {
            lastSaveTime = Time.time;
            SaveManager.Instance.CurrentCheckpointId = checkpointId;
            SaveManager.Instance.Save(currentSlotIndex);
            PlaySaveEffect();
        }
    }
}
```

### 主菜单 — 选档（新增）

```
┌─────────────────────────┐
│     类银河恶魔城          │
│  槽位 1  Lv.5  荒野      │
│  槽位 2  空              │
│  槽位 3  空              │
│  槽位 4  空              │
│   [开始游戏] [删除存档]   │
└─────────────────────────┘
```

- 4 个槽位，每个槽位 = 一个存档 = 一个角色
- 显示等级 + 场景名 + 游玩时间（从 `SaveProfile` 读取）
- 空槽位 → 新游戏
- 选中的槽位 index 传递到 `SaveManager`，之后所有存档/读档操作都用这个 index

## 七、死亡复活流程

### 死亡画面 `UI_DeathScreen`

```
触发：EntityDead 动画播完 → OnEntityDead 事件 → 显示 UI

┌──────────────────────────────┐
│                              │
│       （角色剪影/暗色遮罩）    │
│        你死了                 │
│      死于：骷髅战士            │
│                              │
│   [  回到存档点  ]            │
│   [  返回主菜单  ]            │
└──────────────────────────────┘

回到存档点：SaveManager.Load(当前槽位) → 回到检查点位置
返回主菜单：SceneManager.LoadScene("MainMenu")
```

### 流程

```
1. Entity_Health.Die() → Entity.EntityDead()
2. EntityDead 动画结束 → 触发事件
3. 显示死亡画面：
   - Time.timeScale = 0
   - CanvasGroup.DOFade(1, 0.5f) 淡入
4. 玩家选择：
   - "回到存档点" → SaveManager.Load(slotIndex) → 场景重载/复位
   - "返回主菜单" → Time.timeScale = 1 → SceneManager.LoadScene("MainMenu")
```

## 八、不需要保存的内容

| 内容 | 原因 |
|------|------|
| 敌人存活状态 | 读档场景重置，全部复活 |
| 宝箱状态 | 同上 |
| 门/机关状态 | 同上 |
| 地上的掉落物 | 同上 |
| 临时 Buff/Debuff | 效果在离开场景或读档时自动清除 |
| 技能冷却状态 | 读档全部重置 |
| 攻击连击状态 | 读档重置换 |
| HitStop 状态 | 不需要 |
