# 物品/背包系统重构计划

> 创建日期：2026-07-16
> 状态：待实施

## 一、重构目标

- 消除数据冗余（EquipmentSystem 双字典、三层事件转发）
- 组件职责单一（拆分 ItemAbout 260 行巨型类）
- 简化架构层次（砍掉 3 层不必要的掉落包装）

## 二、新旧架构对比

### 当前架构（10 个类，4 层）

```
数据配置层: ItemDataSo / EquipmentDataSo / ConsumableDataSo
                      ↓
运行时数据层: Inventory_Item / Inventory_Base / Inventory_Player
              EquipmentSystem / Inventory_EquipmentSlot
                      ↓
编排器:      PlayerInventorySystem (纯中间人)
                      ↓
世界物体:    ItemAbout (260 行，职责混杂)
```

### 目标架构（7 个类，3 层）

```
数据配置层: ItemDefinition / EquipmentDefinition / ConsumableDefinition
                      ↓
运行时数据层: ItemInstance / InventoryModel / EquipmentModel (纯 C#，可单元测试)
                      ↓
服务层:     InventoryService / EquipmentService / ConsumableService (MonoBehaviour)
世界物体:   WorldItem + DropItemPhysics + ItemPickupTrigger (组合)
```

## 四、核心数据模型设计

### ItemInstance — 运行时物品实例（纯 C#）

```csharp
public class ItemInstance
{
    public string InstanceId { get; }       // GUID
    public ItemDefinition Definition { get; }
    public int StackSize { get; set; }
    public LootRarity Rarity { get; }
    public float RarityMultiplier { get; }
    public IReadOnlyList<ItemModifier> Modifiers { get; }

    public bool IsEquipment => Definition is EquipmentDefinition;
    public bool IsConsumable => Definition is ConsumableDefinition;
    public bool CanStackMore => Definition.canStack && StackSize < Definition.maxStack;
}
```

### InventoryModel — 背包数据（纯 C#）

```csharp
public class InventoryModel
{
    private readonly ItemInstance?[] _slots;
    public int SlotCount { get; }
    public bool IsFull { get; }
    public ItemInstance? GetSlot(int index);

    public bool TryAddItem(ItemInstance item, out int slotIndex);
    public bool TryAddAt(ItemInstance item, int slotIndex, out ItemInstance? conflict);
    public bool TryRemove(int slotIndex, out ItemInstance? removed);
    public bool TryRemove(string instanceId, out ItemInstance? removed);
    public bool TrySwap(int a, int b);

    public event Action<int> SlotChanged;
}
```

### EquipmentModel — 装备槽数据（纯 C#）

```csharp
public class EquipmentModel
{
    private readonly Dictionary<ItemType, ItemInstance?[]> _slots;

    public bool TryEquip(ItemInstance item, int slotIndex, out ItemInstance? replaced);
    public bool TryUnequip(int slotIndex, out ItemInstance? removed);
    public bool TryUnequip(string instanceId, out ItemInstance? removed);
    public ItemInstance? GetSlot(ItemType type, int index);

    public event Action<ItemType, int> SlotChanged;
}
```

## 六、实施顺序

```
第1步: Model 层（纯 C#，可单独测试）
   ItemInstance.cs → InventoryModel.cs → EquipmentModel.cs

第2步: Service 层（挂到场景中，旧代码还能用）
   InventoryService.cs → EquipmentService.cs → ConsumableService.cs → LootService.cs

第3步: 替换世界物品
   WorldItem.cs + DropItemPhysics.cs + ItemPickupTrigger.cs
   目的：拆分 ItemAbout 260 行的混杂职责为独立组件

第4步: 简化掉落系统
   砍掉 LootPool / LootDropItem / LootedItem 三个包装层
   LootTable 直接产出 ItemInstance[]
   目的：去掉没必要的嵌套封装

第5步: UI 迁移 + 删除旧文件
   改事件订阅 → 删 11 个旧类 → 验证全部交互
```
