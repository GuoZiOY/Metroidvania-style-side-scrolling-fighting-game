# 技能系统改进总结

## 核心改进

### 1. 统一升级追踪系统

**totalLevel 机制**
- 在 `Skill_Base.cs` 中实现统一的 `totalLevel` 追踪
- 记录当前技能类型的总升级次数（跨升级类型）
- 通过 `upgradeTypeLevels` 字典记录每个升级类型的等级
- 重置技能时自动清除 `totalLevel` 和所有升级类型等级

**关键代码**
```csharp
protected Dictionary<SkillUpgradeType, int> upgradeTypeLevels = new Dictionary<SkillUpgradeType, int>();
protected int totalLevel = -1;

public virtual void SetSkillLevelData(SkillUpgradeType upgradeType, LevelData levelData, int level)
{
    totalLevel++;
    upgradeTypeLevels[upgradeType] = level;
}

public virtual void RefundSkillUpgrade()
{
    totalLevel = 0;
    upgradeTypeLevels.Clear();
}
```

### 2. 领域技能升级加成

**实现功能**
- 基于 `totalLevel` 的累积加成系统
- 每级增加范围和持续时间
- 升级领域类型时加成不重置
- 重置技能时完全恢复基础值

**加成规则**
- 范围加成：`baseRange + totalLevel * rangeAdd`
- 持续时间加成：`baseDuration + totalLevel * durationAdd`

### 3. 元素技能附魔系统

**动态附魔次数**
- 最大附魔次数 = 基础次数 + (总等级 / 3)
- 每 3 级增加 1 次附魔机会
- 基于基础技能类型确定元素类型
- 未来扩展新技能时自动适配

**代码优化**
- 将 `TryUseSkill` 方法集中到 `Skill_ElementalBase` 基类
- 消除各元素技能实现中的冗余代码
- 使用 `baseSkillType` 动态确定元素类型

### 4. 冲刺技能平衡系统

**多重加成机制**
- 基础加成：基于 `effectiveTotalLevel` 的线性增长
- 类型加成：不同升级类型提供不同加成
  - `Dash` 类型：每级额外增加速度 0.2
  - `Dash_Blur` 类型：每级额外增加持续时间 0.01
- 镜像回声加成：虚化类型每级减少镜像回声间隔 0.004

**平衡限制**
- `totalLevel` 上限：10 级
- 镜像回声间隔下限：0.04 秒
- 目标距离：初始 4.5，最终 6.0

**参数配置**
```csharp
[SerializeField] private float dashSpeedAdd = 0.01f;           // 每级增加速度
[SerializeField] private float dashDurationAdd = 0.0012f;       // 每级增加时间
[SerializeField] private float dashSpeedAddPerLevel = 0.2f;     // 冲刺类型额外加成
[SerializeField] private float dashDurationAddPerLevel = 0.01f; // 虚化类型额外加成
[SerializeField] private float imageEchoIntervalSubtract = 0.004f; // 镜像回声间隔减少
private const int maxTotalLevel = 10;                           // 等级上限
```

**代码重构**
- 提取 `GetUpgradeTypeLevel()` 方法：获取升级类型等级
- 提取 `ApplyDashBonuses()` 方法：应用所有冲刺加成
- 将基础值初始化从 `Awake` 移至 `Start`，解决空引用异常
