# 地图区域设计 — 破碎之城 MVP 3区域

> **Status**: Designed | **Date**: 2026-07-29 | **Implements**: Pillar 1 + 4

## Overview

破碎之城 MVP 包含 1 个中心城镇 + 3 个互连区域，每个区域有独立主题、敌人构成、Boss 和能力门控。区域通过传送门连接曙光城（中心辐射），区域内设计为银河城式高度互联（捷径、隐藏墙、能力门控回环）。

## 三区域结构

```
曙光城 (Hub)
  ├── 传送门 → 区域1: 废弃矿坑 (Abandoned Mines)
  ├── 传送门 → 区域2: 腐蚀庭院 (Corrupted Gardens)
  └── 传送门 → 区域3: 破碎王座 (Shattered Throne)
```

## 区域1: 废弃矿坑 (Abandoned Mines)

**主题**: 幽暗地下矿道 + 结晶洞穴
**难度**: 入门 — 敌人 Lv1-5
**风格**: 暗色岩壁 + 发光矿脉(火元素主题暖光)

| 维度 | 详情 |
|------|------|
| **敌人** | 矿工骷髅(普通)、结晶蝙蝠、矿车魔像(精英) |
| **Boss** | 熔核巨像 (Magma Core Golem) — 2阶段, 火元素主题 |
| **门控** | 入口无门控 — 从曙光城传送门直达 |
| **解锁** | Boss击败 → 获得 **无敌冲刺 (DashBlur)** |
| **隐藏** | 3个隐藏房间: 含早期稀有装备 / 材料 |
| **捷径** | Boss房间外有回城传送门 |

**核心探索路径**:
```
入口 → 结晶通道(战斗教学) → 矿工营地(精英首次遭遇)
  → 深矿层 → 隐藏房间×1 → 升降机(捷径解锁)
  → 熔核巢穴(Boss房间) → 解锁DashBlur
```

## 区域2: 腐蚀庭院 (Corrupted Gardens)

**主题**: 曾经的王室花园 + 腐蚀性能量污染
**难度**: 中级 — 敌人 Lv4-8
**风格**: 枯死植物 + 紫色腐蚀池 + 大理石废墟

| 维度 | 详情 |
|------|------|
| **敌人** | 腐蚀藤蔓、石像守卫、荒芜精灵(精英) |
| **Boss** | 枯败女王 (Withered Queen) — 3阶段, 毒/召唤主题 |
| **门控** | 入口需 **DashBlur** — 通过腐蚀通道(持续伤害地形) |
| **解锁** | Boss击败 → 获得 **二段跳 (DoubleJump)** |
| **隐藏** | 4个隐藏房间: 含独特装备 / 宝石 / 材料 |
| **捷径** | DashBlur可破的隐藏墙 ×2；解锁二段跳后可到达的新平台 |

**核心探索路径**:
```
入口(需DashBlur过腐蚀通道) → 花园前庭 → 隐藏房间×1
  → 温室废墟 → 精英遭遇 → 捷径(解锁回城)
  → 女王寝宫(Boss房间) → 解锁DoubleJump
```

## 区域3: 破碎王座 (Shattered Throne)

**主题**: 崩塌的城堡 + 虚空裂痕
**难度**: 高级 — 敌人 Lv7-12
**风格**: 哥特城堡残骸 + 虚渊蓝色裂痕 + 飘浮碎片平台

| 维度 | 详情 |
|------|------|
| **敌人** | 王座守卫、虚空裂兽、堕落骑士(精英) |
| **Boss** | 虚空主宰 (Void Sovereign) — 3阶段, 虚空/暗元素主题 |
| **门控** | 入口需 **DashBlur + DoubleJump** — 跨越大裂缝 |
| **解锁** | Boss击败 → 最终任务完成 / 结局触发 |
| **隐藏** | 5个隐藏房间: 含传说级装备 / 最高级材料 / 隐藏Boss线索 |
| **捷径** | 全区域最多的捷径回环(展示已掌握全部能力) |

**核心探索路径**:
```
入口(需DashBlur+DoubleJump跨裂缝) → 城堡外墙(垂直平台)
  → 王座前厅 → 隐藏房间×2 → 捷径(回城)
  → 虚空裂痕(Boss房间) → 最终Boss
```

## 能力曲线

```
开局: 冲刺 (Dash) — 初始拥有
区域1 Boss: 无敌冲刺 (DashBlur) — 通过伤害地形
区域2 Boss: 二段跳 (DoubleJump) — 到达高平台
区域3 入口: DashBlur + DoubleJump — 跨越大裂缝+高台
```

## 难度曲线

| 区域 | 敌人等级 | 精英/房间 | Boss阶段 | 推荐装备稀有度 |
|------|----------|-----------|----------|----------------|
| 矿坑 | 1-5 | 2-3 | 2 | 普通-精良 |
| 庭院 | 4-8 | 3-4 | 3 | 精良-稀有 |
| 王座 | 7-12 | 4-5 | 3 | 稀有-史诗 |

## Edge Cases

- **seq break 到达未解锁区域**: 允许(不设硬锁)，但伤害通道/高度差自然阻挡
- **区域Boss未击败就找到下一区域入口**: 门控挡路(物理/地形)，但允许反向探索
- **区域全部敌人清空后返回**: 敌人不重生，精英重生时间=回城后刷新

## Dependencies

| 系统 | 使用 |
|------|------|

| Boss系统 (F7) | 每区域Boss配置 |
| 传送门 (C15) | 区域入口+回城传送门位置 |
| 精英词缀 (C14) | 每区域精英怪词缀池 |
| 敌人系统 (C4) | 每区域敌人构成+等级 |
| 世界条件 (P1) | 全局缩放可能影响区域实际难度 |
| 掉落系统 (C7) | 区域专属掉落表 |

## Visual/Audio Requirements

- 每区域独立调色板: 矿坑(暖橙+暗褐)、庭院(紫+灰绿)、王座(深蓝+金)
- 区域BGM: 矿坑(深沉打击乐)、庭院(不和谐弦乐)、王座(管风琴+合唱)
- 传送门光泽: 对应区域主题色

## Acceptance Criteria

- **GIVEN** 新游戏，**WHEN** 从曙光城传送门出发，**THEN** 可到达矿坑入口
- **GIVEN** 击败矿坑Boss获得DashBlur，**WHEN** 回城后从庭院传送门出发，**THEN** DashBlur可通过入口腐蚀通道
- **GIVEN** 击败庭院Boss获得二段跳，**WHEN** 前往王座，**THEN** DashBlur+二段跳可跨越入口裂缝
