# 史莱姆王 Boss（King Slime）— v4 重设计

> **Status**: Designed (v4 重设计)
> **Author**: oy + Claude
> **Last Updated**: 2026-08-13
> **Implements Pillar**: Pillar 4 (掌握带来力量) + Pillar 2 (掉落改变打法)

## Overview

史莱姆王是第一个 Boss，泰拉瑞亚复刻。本次为**大规模专业级架构重设计**：取消所有入场演出（最简流程），重做 Boss 机制（多阶段：常态/分裂狂暴/濒死隐身），并把框架精简为"通用编排 + Boss 专属内容 + 统一伤害"三层，供未来 Boss 复用。

## Player Fantasy

走进 Boss 房，传送门在身后关闭，BGM 切换，血条浮现——开打。玩家立刻能动的第一个 Boss 战，没有冗长开场。史莱姆王从大跳到冲刺到头顶砸落，节奏越来越快；残血时爆成两只、濒死时隐身回血，逼玩家清杂打断——"我读懂了它的节奏，最终赢了"。

## Boss 机制（定稿）

### 阶段与阈值

| 阶段 | 触发 | 行为 |
|------|------|------|
| **常态** | 100% → 30% | 大跳触碰（落地提示）/ 冲刺（无提示）/ 传送攻击（超距头顶落下）/ 召唤低级史莱姆 |
| **分裂狂暴** | HP < 30% | 分裂成 2 个各半血 → 都频繁跳/冲 → 杀一只 → 存活者回血到 29% → 僵直 → 僵直后连续 3 段快速冲刺 → **不再分裂** |
| **濒死隐身** | HP < 1% | 隐身半透明、无法移动/攻击、频繁召唤史莱姆、缓慢回血（**最多 29%**，不重复触发分裂）、史莱姆杀光提前退出隐身 |

### 动作与伤害

| 动作 | 伤害 | 说明 |
|------|------|------|
| **大跳触碰攻击** | 普通（12% MaxHP） | 落地投影阴影提示（提前 0.8s）；落地后摇 1.0s = 惩罚窗口（接触关闭） |
| **冲刺攻击** | **1.5x**（18%） | 锁定方向快速横冲，**无提示**（难度选择）；速度/距离手动调 |
| **传送攻击** | **2x**（24%） | 距玩家过远触发；传送闪光预告，头顶落下触碰；落地停顿 0.5s |
| **召唤低级史莱姆** | — | 复用 `Enemy_Slime`（现成、可分裂、低等级纯干扰） |

### 伤害公平
- 玩家受击无敌帧 0.7s（`Entity_Health.Invincible Duration`）→ 一次失误最多吃一下
- 身体接触伤害 = Boss 脚本内自带（`OnTriggerStay2D` + 每源冷却 1s），落地后摇期间关闭

## Boss 房流程（最简，定稿）

```
玩家进入 Boss 房（传送门）→ 锁到达传送门（不能回头）
  → 切 Boss BGM + 血条显示
  → Boss 直接开打，玩家立刻能动（无任何开场演出）
  → 击杀 → 出口传送门出现（指向城镇）
  → 死亡 → 现有死亡面板读档回存档点（场景卸载重置 Boss）
```

## 框架架构（精简分层）

```
BossEncounter（通用编排器，未来 Boss 零改动）
  ├─ 场景生命周期：锁传送门 → 切BGM → 绑血条 → 开战 → 击杀/死亡
  └─ 不管 Boss 怎么打（Boss 只暴露 BeginFight() / Enemy 基础）

Boss_SlimeKing（Boss 专属内容）
  ├─ 动作池：大跳触碰 / 冲刺 / 传送攻击 / 召唤史莱姆
  ├─ 阶段状态机：常态 → 分裂(2实例) → 存活者 → 濒死隐身
  │   └─ 多体管理：分裂出第2实例、血条绑存活者、胜利=最后实例死亡
  └─ 身体接触伤害（内置 OnTriggerStay2D + 每源冷却）

基础设施（通用复用）
  ├─ UI_BossHealthBar / AudioManager BGM(push/pop) / Portal(SetLocked)
  ├─ 玩家受击无敌帧（Entity_Health）
  └─ 召唤物复用 Enemy_Slime（现成敌人）

已删除：ContactDamageArea.cs（并入 Boss 脚本）、Boss_SlimeMinion（召唤改用普通史莱姆）
```

## Formulas

- 伤害预算：接触 12% / 冲刺 18%（1.5x）/ 传送 24%（2x）MaxHP；一次失误最多吃一下（无敌帧 0.7s）
- 分裂：HP<30% 爆 2 个各 15%；杀一只 → 存活者回血到 29% → 僵直 → 3 段冲刺
- 濒死：HP<1% 隐身；回血最多 29%（< 30% 分裂阈值，不重复触发）；杀光史莱姆提前退出
- 落地后摇：1.0s（惩罚窗口，接触关闭）；传送落地停顿 0.5s

## Edge Cases

- **分裂后只剩一只**：存活者回血 29% → 僵直 → 3 段冲刺 → 不再分裂 → 继续常态
- **分裂后两只几乎同时死**：最后存活者判定（若同时，选血量高的存活）
- **濒死隐身中玩家清史莱姆**：杀光立即退出隐身恢复战斗；回血被封顶 29% 不会重新触发分裂
- **玩家死亡**：现有死亡面板 → 读档回存档点；场景卸载 Boss 重置
- **Boss 被一击秒杀跨阈值**：直接死亡，跳过分裂/隐身
- **重复进入**：MVP 默认不可重打（已击败标志，WorldState 待实现）

## Acceptance Criteria

- **GIVEN** 玩家进入 Boss 房，**WHEN** 传送门到达，**THEN** 到达门锁定、BGM 切、血条显示、Boss 直接开打（无开场演出、玩家立刻能动）
- **GIVEN** 常态战斗，**WHEN** Boss 出招，**THEN** 大跳有落地投影提示、冲刺无提示横冲、超距传送头顶落下、周期性召唤普通史莱姆（可分裂）
- **GIVEN** HP<30%，**WHEN** 分裂，**THEN** 爆成 2 个小史莱姆王各半血，都频繁跳/冲；杀一只 → 存活者回血 29% → 僵直 → 3 段冲刺 → 不再分裂
- **GIVEN** HP<1%，**WHEN** 濒死，**THEN** 隐身半透明、无法移动攻击、频繁召唤、缓慢回血（最多 29%）；史莱姆杀光提前退出隐身
- **GIVEN** Boss 死亡，**WHEN** 最后实例死亡，**THEN** 血条隐藏、BGM 恢复、出口传送门激活
- **GIVEN** 玩家死亡，**WHEN** 读档，**THEN** 回到存档点，重进 Boss 房 Boss 重置
