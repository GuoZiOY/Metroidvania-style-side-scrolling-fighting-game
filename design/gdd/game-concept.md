## Elevator Pitch

**10 秒版**: "暗黑式刷宝的银河恶魔城——从中心城镇出发，高速冲刺探索互连区域，击杀精英刷稀有装备，用掉落定义你的 Build。"

**详细版**: 破碎之城是一款融合暗黑式 ARPG 装备驱动成长与银河恶魔城能力门控探索的 2D 横版动作游戏。玩家从最后的避难所"曙光城"出发，通过传送门进入被腐蚀的荒野外域。每一次远征都可能改变你的 Build——掉落的词缀装备不是简单的数值提升，而是新打法的钥匙。

## Game Pillars

### Pillar 1: "每一次冲刺都是一次发现"
高速移动是探索的核心工具——Dash 穿过隐藏墙、滑铲进入密道、空中冲刺到达隐藏平台。

**设计检验**: "这个新内容能通过移动技能被发现吗？"

### Pillar 2: "每一次掉落都可能改变我的打法"
掉落不只是一个数值提升，而是一个可能的新 Build 方向。

**设计检验**: "这件装备能让我思考'要不要换Build'吗？"

### Pillar 3: "城镇是家，荒野是猎场"
中心辐射——城镇是整理/打造/接任务的避难所；每次出门都是一次有目的远征。

**设计检验**: "这个新内容能找到从城镇出发再回来的自然循环吗？"

### Pillar 4: "掌握带来力量，力量打开世界"
新区域不仅需要新移动能力，也需要足够的装备水平。

**设计检验**: "解锁这个区域需要玩家证明操作还是Build深度？"

## Anti-Pillars

- **不做随机生成地图** — 手绘式银河恶魔城地图的精密感是核心
- **不做硬核死亡惩罚** — 不掉经验/不掉装备，保持探索轻松感
- **不做过场动画叙事** — 世界通过环境、NPC对话、物品描述讲故事

## Core Loop

### 30-Second Loop (瞬间)
高速移动(Dash+滑铲) → 遭遇敌人 → 连击×技能×元素 → 击杀 → 掉落光泽反馈

### 5-Minute Loop (短期)
探索房间群 → 遭遇精英(词缀) → 稀有掉落 → 发现捷径/隐藏 → 开传送门回城

### Session Loop (30-90分钟)
城镇出发 → 选择区域(传送门) → 探索+战斗+收集 → 击败区域Boss → 获得新能力/装备 → 回城整理Build → 再出发

### Progression Loop (数天)
解锁新区 → 新敌人 → 新装备层级 → 新Build → 更高难度 → 解锁更多

## Scope Tiers

### MVP (毕业设计演示 — 前3个月)
- 1 个城镇 (曙光城) + 3 个完整区域
- 3 个区域 Boss + 1 个隐藏 Boss
- 装备词缀系统 (前缀+后缀)
- 核心游戏循环 (探索→战斗→掉落→回城→再出发)
- 已有的全部战斗/技能/元素/任务系统

### Target (实习演示 — 后3个月)
- 扩展至 5-6 个区域 + 5-6 个 Boss
- Boss 追踪系统 (传闻→线索→讨伐)
- 宝石/符文镶嵌
- 世界条件系统
- Build 存档槽

### Full Vision (正式发布)
- 6+ 区域 + 隐藏区域
- 新游戏+ (NG+)
- Boss Rush 模式
- 完整 NPC 剧情线
- 更多装备词缀和传奇装备

## Key Risks

| 风险 | 类型 | 缓解措施 |
|------|------|----------|
| 关卡设计工作量大 | 开发 | MVP仅3区域，用已有敌人/资产填充 |
| 词缀平衡失控 | 设计 | 用公式约束数值范围，Build测试工具 |
| 中心辐射式地图缺乏探索感 | 设计 | 每个区域内部用银河城式高度互联 |
| 美术资产不足 | 资源 | 复用现有资产 + 调色板区分区域 |

## Visual Identity Anchor

**视觉方向**: 暗黑哥特——破败的维多利亚式建筑 + 腐蚀性能量痕迹

**视觉规则**: "每一个场景都必须传达它曾经辉煌、现在破碎"

**色彩哲学**: 暖色(灯火/火焰) = 安全/文明；冷色(腐蚀/冰霜) = 危险/野外
