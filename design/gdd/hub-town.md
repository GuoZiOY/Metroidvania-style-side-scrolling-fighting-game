# 中心城镇 — 曙光城

> **Status**: Designed
> **Author**: oy + Claude
> **Last Updated**: 2026-07-29
> **Implements Pillar**: Pillar 3 (城镇是家，荒野是猎场)

## Overview

曙光城是破碎之城中最后的避难所——一个独立场景，包含传送门大厅、NPC、商店、仓库和任务板。玩家每次远征从这里出发，通过传送门选择目的地区域。战斗结束后通过区域内的返回传送门回到这里整理装备、出售战利品、接取新任务、升级技能。城镇是 Pillar 3 的物理锚点。

## Player Fantasy

暗黑2 的 rogue encampment——走出城门时的"未知在等待"，打完回来时的"安全了"。城镇的背景音乐、NPC 对话、传送门的光泽共同营造"这是家"的感觉。每次远征回来，城镇都是那个不变的安全点。

## Detailed Design

### Core Rules

**城镇场景结构**:
```
曙光城 (独立 Unity Scene)
├── 传送门大厅 (PortalNetwork 传送门 × N)
├── NPC 区域 (商人/铁匠/任务NPC)
├── 仓库 (共享存储箱)
├── 任务板 (可选)
└── 出生点 (玩家回城 + 游戏开始位置)
```

**城镇功能清单**:
| 功能 | 实现方式 | 依赖 |
|------|----------|------|
| 传送门 | PortalNetwork | C15 |
| 商店(买卖) | ShopSystem + ShopSO | C8 |
| NPC对话/任务 | NPCBehaviour + QuestManager | C12 |
| 技能树 | UI_SkillTree | C2 |
| 装备管理 | Inventory + Equipment UI | C3-C9 |
| 仓库(可选) | 额外存储槽 | — |

**城镇流程**:
```
游戏开始 → 曙光城出生点 → 玩家熟悉城镇
→ 与NPC对话接任务 → 通过传送门选区域 → 远征
→ 区域Boss击败/背包满 → 返回传送门 → 回城
→ 卖装备/整理Build/接新任务 → 再出发
```

### States and Transitions

无状态机。城镇是静态安全区：无敌人、无伤害、无战斗。

### Interactions

| 系统 | 方向 | 接口 |
|------|------|------|
| 传送门网络 (C15) | ←核心 | 传送门GameObject在城镇场景中 |
| 商店系统 (C8) | ←核心 | ShopSystem + UI_ShopPanel |
| 任务系统 (C12) | ←核心 | NPCBehaviour + NPC 任务对话 |
| 技能系统 (C2) | ←核心 | UI_SkillTree 面板 |
| 存档系统 (F2) | → | 城镇作为存档点 |

## Formulas

无。

## Edge Cases

- **场景首次加载**: NPC状态从存档恢复(已完成任务的NPC显示不同对话)
- **所有传送门未激活时**: 传送门大厅显示"尚未连接任何区域"提示
- **回到城镇时背包满+有新掉落**: 玩家需要先处理背包才能再出发

## Tuning Knobs

| 参数 | 值 | 说明 |
|------|-----|------|
| 城镇BGM | 舒缓、安全 | 与战斗BGM形成对比 |
| 城镇尺寸 | 小型(1屏) | 紧凑，步行10秒可达所有功能 |
| NPC数量 | 2-4 | MVP不建议太多 |

## Visual/Audio Requirements

- 城镇BGM: 舒缓弦乐 + 环境音(火堆噼啪)
- 传送门大厅: 激活的传送门发光+区域主题色粒子
- NPC: 基础站立动画 + 玩家靠近时面向玩家
- 背景: 破败的维多利亚建筑 + 暖色灯光(安全信号)

## Acceptance Criteria

- **GIVEN** 游戏启动/新游戏，**WHEN** 加载完成，**THEN** 玩家出现在曙光城出生点
- **GIVEN** 玩家在城镇中，**WHEN** 与传送门交互，**THEN** 加载对应区域场景
- **GIVEN** 玩家在区域中通过返回传送门，**WHEN** 传送回城，**THEN** 出现在传送门大厅
- **GIVEN** 玩家在城镇中，**WHEN** 尝试攻击，**THEN** 无攻击判定(安全区)
