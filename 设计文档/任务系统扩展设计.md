# 任务系统扩展设计

---

## 一、设计目标

- 任务系统从「接→做→交」三明治升级为多阶段叙事
- 所有任务操作（接取/提交/领奖）统一走 NPC 交互，面板只做日志查阅
- NPC 与任务的交互通过对话菜单驱动
- 提供可视化任务树编辑器，让任务配置归并化、结构化（二期）

## 三、数据结构

### 3.1 QuestData

```csharp
[CreateAssetMenu(menuName = "RPG设置/任务系统/任务数据", fileName = "QuestData -")]
public class QuestData : ScriptableObject
{
    [Header("基础信息")]
    public string questId;
    public string questName;
    public QuestType questType;               // Main / Side / Temporary
    [TextArea] public string description;

    [Header("触发配置")]
    public QuestTrigger trigger;              // NpcTalk / AutoUnlock / ItemPickup
    public string triggerNpcId;               // 从哪个 NPC 接取
    public string triggerItemId;              // 拾取哪个物品触发
    public bool autoAccept;                   // 接取后是否自动接受

    [Header("前置条件")]
    public List<string> prerequisiteQuestIds;

    [Header("阶段")]
    public List<QuestStage> stages;

    [Header("最终奖励")]
    public QuestReward finalReward;

    [Header("后续任务")]
    public List<string> followUpQuestIds;

    [Header("完成时设置的世界状态")]
    public List<string> setWorldFlags;
}
```

```csharp
[System.Serializable]
```

## 四、QuestManager 扩展

### 4.1 任务状态

```
未接取         → GetAvailableQuests() 中列出
进行中(stage)  → 当前在某阶段内，目标逐步完成
阶段完成       → 当前阶段目标完成，待找 NPC 推进到下一阶段
最终阶段完成   → 最终阶段目标完成，待找 NPC 领奖
已完成         → 最终奖励已领取
已失败         → 时间超限/条件失败
```

### 4.2 核心方法

```csharp
// 接取任务 → 初始化为第一阶段
AcceptQuest(string questId) → bool

// 获取当前阶段
GetCurrentStage(string questId) → QuestStage

// 获取当前阶段的进度数组
GetStageProgress(string questId) → int[]

// 检查当前阶段是否完成
IsCurrentStageComplete(string questId) → bool

// 推进到下一阶段（NPC 对话中调用）
AdvanceToNextStage(string questId) → bool

// 领取最终奖励 → 任务完成
ClaimFinalReward(string questId) → bool
```

### 4.3 事件

```csharp
// 已有
OnQuestAccepted(string questId)
OnObjectiveUpdated(string questId, int objIndex, int current)
OnQuestFailed(string questId)

// 新增
OnQuestStageChanged(string questId, string stageId)
OnQuestReadyToClaim(string questId)     // 最终阶段完成
OnQuestClaimed(string questId)          // 奖励已领取
```

### 4.4 进度更新

`QuestManager` 监听 `QuestEvents`，对所有进行中的任务按阶段推进：

```csharp
// 击杀检测：遍历所有进行中任务的当前阶段，匹配 Kill 目标
OnEnemyKilled(enemyId) → 匹配 → 当前阶段目标进度+1

// 收集检测：遍历所有进行中任务的当前阶段，匹配 Collect 目标
OnItemCollected(itemId, count) → 匹配 → 当前阶段目标进度+count

// 对话检测：遍历所有进行中任务的当前阶段，匹配 TalkToNPC 目标
OnNpcTalked(npcId) → 匹配 → 当前阶段目标进度+1
```

每项目标进度达到 `requiredCount` 后停止增长。当前阶段所有目标完成后，自动变为「阶段完成」状态（不自动推进，等 NPC 对话触发推进）。

## 五、NPCQuestGiver 组件

挂在 NPC 上，和 `NPCBehaviour` 协作。

```csharp
public class NPCQuestGiver : MonoBehaviour
{
    [Header("NPC 标识")]
    public string npcId;

    [Header("关联任务")]
    public List<QuestData> questsToGive;

    [Header("问候对话")]
    [TextArea] public string[] greetingLines;

    // ─── 运行时查询 ───

    // 是否有可接取的任务
    public bool HasAvailableQuest() { ... }

    // 是否有阶段可提交（当前阶段完成 but 不是最终）
    public bool HasStageToSubmit() { ... }

    // 最终阶段完成待领奖
    public bool HasFinalRewardToClaim() { ... }

    // 任一任务在进度中
    public bool HasActiveQuest() { ... }
}
```

### 对话菜单显示规则

```
菜单项     | 显示条件
──────────┼──────────────────────────
📋 任务    | HasAvailableQuest || HasStageToSubmit || HasFinalRewardToClaim
🏪 商店    | 关联的 NPCBehaviour.shopData != null
💬 对话    | 始终显示
🚪 离开    | 始终显示
```

### NPCBehaviour.Update 扩展

```
按 F → 打开对话菜单
  ├── [任务] → 判断优先级:
  │     HasFinalRewardToClaim  → 打开对话面板(领奖态)
  │     HasStageToSubmit       → 打开对话面板(阶段完成态)
  │     HasAvailableQuest      → 打开对话面板(接取态)
  │     有进行中任务            → 打开对话面板(进行中态)
  ├── [商店] → UI_ShopPanel.Open(shopData)
  ├── [对话] → 打开对话面板(问候态)
  └── [离开] → 关菜单
```

```csharp
{
    [SerializeField] private TextMeshProUGUI npcNameText;
    [SerializeField] private TextMeshProUGUI dialogueText;

    [SerializeField] private Button primaryButton;
    [SerializeField] private Button secondaryButton;

    public void ShowForAccept(NPCQuestGiver giver, QuestData quest);
    public void ShowForInProgress(NPCQuestGiver giver, QuestData quest);
    public void ShowForStageComplete(NPCQuestGiver giver, QuestData quest);
    public void ShowForFinalClaim(NPCQuestGiver giver, QuestData quest);
    public void ShowGreeting(NPCQuestGiver giver);

```

呈现模式对应：

```
接取态     → primary: [接受]  → AcceptQuest + 关面板
               secondary: [下次再说] → 关面板

进行中态   → primary: [继续]  → 关面板
               secondary: 隐藏

阶段完成态 → primary: [继续]  → AdvanceToNextStage + 刷新面板
               secondary: 隐藏

最终完成态 → primary: [领取奖励] → ClaimFinalReward + 关面板
               secondary: [离开] → 关面板
```

```csharp
public static class WorldState

    private static Dictionary<string, bool> flags = new();
```

## 九、可视化任务树编辑器（二期）

### 9.1 功能

- 在 Unity 编辑器窗口中可视化创建/编辑任务
- 节点间连线表示前置→后续关系
- 右侧属性面板直接编辑 QuestData 全部参数
- 一键导出为 QuestData ScriptableObject

### 9.2 技术栈

```
UnityEditor.GraphView   → 画板 + 节点 + 连线
UIToolkit               → 属性面板
ScriptableObject        → 持久化
AssetDatabase           → SO 创建/保存
```
